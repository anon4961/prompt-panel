# Prompt Panel

SillyTavern의 프리셋, 월드인포, 캐릭터카드를 한 패널에서 열람·번역·검색·내보내기 할 수 있는 확장입니다.

## 주요 기능

### 데이터 로드
현재 사용자의 SillyTavern에 등록된 **프리셋, 월드인포, 캐릭터카드**를 패널에서 직접 로드해서 보여줍니다.

이름 칸을 누르면 목록 창이 열립니다. 선택 후 `📂 로드`를 누르면 프리셋을 불러옵니다.
- **찾기**: 위쪽 검색칸에 이름 입력. 초성, 제목 일부, 번역문으로도 검색 가능
- **최근**: 최근에 `📂 로드`로 불러온 5개를 따로 보여줌
- **이름 번역 📛**: 목록에 있는 이름(프리셋·월드인포·캐릭터)을 번역하는 옵션. 누르면 목록에 체크 박스가 생기고, 번역할 이름을 선택 후 번역. 설정의 `제목 번역 묶음 개수`만큼 묶어 요청함. 이미 번역된 이름은 건너뛰며, 이미 번역된 것만 골랐다면 다시 번역할지 선택 가능. 번역 언어가 한국어이면 이미 한국어인 이름은 보내지 않음.
- **👀**: 번역된 이름으로 보기 / 원래 이름으로 보기. 번역이 끝나면 저절로 켜지며, 번역된 이름 아래에 원래 이름이 작게 함께 보입니다.
- 번역된 이름은 **패널 안에서만** 보임. 실제 프리셋·월드인포·캐릭터 이름은 바꾸지 않음. 번역 캐시 백업에 함께 들어갑니다.
- 이름이 같은 캐릭터카드가 여럿이면 파일명이 함께 표시됨

### 번역
- 토글/엔트리/필드 단위 번역, 개별 재번역
- 번역 캐시는 브라우저 IndexedDB에 저장 (SillyTavern 설정 파일에 저장하지 않음)
- **번역 캐시 백업·가져오기**: 확장 설정의 번역 캐시 구역에서 캐시 전체를 파일로 백업하고 다시 가져올 수 있음.
- 지원 프로바이더: OpenAI, Claude, Google AI Studio (MakerSuite), Vertex AI, OpenRouter, DeepSeek, Z.AI (GLM), **Custom (OpenAI 호환)**
  - **Custom**: OpenAI 호환 주소(보통 `/v1`로 끝남)와 API 키를 넣어 다른 서비스를 직접 연결(Mistral, Groq, xAI, 중계 API, 로컬 서버 등). `모델 목록 불러오기`를 누르면 연결을 확인하면서 모델을 고를 수 있음. 입력한 키는 브라우저(IndexedDB)에만 저장되며 SillyTavern 설정 파일이나 백업에는 들어가지 않음. 키를 비워 두면 SillyTavern에 **같은 주소로** 저장해 둔 키(Custom 연결 프로필의 키, 리버스 프록시 프리셋의 비밀번호, 같은 주소를 가리키는 Custom 연결의 현재 키)를 자동으로 찾음. 어떤 키가 쓰이는지는 키 칸과 `모델 목록 불러오기` 결과에 표시됨. 프리필은 보내지 않음.
  - 각 제공사 지침에 맞춰, 최신 모델에는 켜져 있어도 보내지 않는 값이 있음. Temperature 등 샘플링 값: GPT-5.5 이후·GPT-6, Claude Opus 4.7 이후·Claude 5·Fable, Gemini 3.5 이후. 프리필: Gemini 3.5 이후, Claude 4.6 이후.
- **프리셋 용어집**: 실리태번 관련 커뮤니티에서 쓰는 은어의 뜻이 따로 정의됨. 수정 및 추가 가능. 브라우저 IndexedDB에 따로 저장되며, 번역 캐시 전체 삭제로 지워지지 않음
- **SillyTavern 기본 토글 이름**: `Chat History`, `World Info (before)`, `Persona Description` 같은 SillyTavern 기본 토글은 이름을 바꾸지 않은 경우 번역 요청 없이 한국어 이름을 바로 보여줌
- **캐릭터카드 항목 이름**: 캐릭터 설명, 성격 요약, 시나리오, 첫 메시지, 대화 예시, 대체 인사말 같은 캐릭터카드 항목 이름도 번역 요청 없이 확장이 바로 보여주며 📛를 눌러도 요청하지 않음
- **같은 원문 번역 가져오기**: 프리셋을 고쳐서 다른 이름으로 저장한 경우처럼, 다른 프리셋에 **이름과 내용이 똑같은 토글**의 번역이 있으면 불러올 때 안내됨. `가져오기`를 누르면 해당 번역이 복사됨. 내용이 바뀐 토글은 이름이 같으면 제목 번역만 가져옴(프리셋 탭 전용)
- **📛 제목 번역**: 제목만 빠르게 번역. 여러 제목을 한 요청으로 묶어 보냄. 본문 번역과 별도로 저장됨.
- **👀 제목 보기**: 패널에 보이는 토글 제목을 번역본으로 전환하며 다시 누르면 원어로 돌아감
- **번역 언어 직접 지정**: 드롭다운의 `⚙️ 직접 입력`을 고르면 원하는 언어를 입력(영어 언어명 권장, 예: French).
- **월드인포 키워드 번역**: 엔트리의 키워드(Primary Keywords)와 보조 키워드(Optional Filter)가 번역 본문 앞부분에 함께 표시되며, JSON 내보내기 시 각각 `key`, `keysecondary` 필드에 해당됨.
  - 기본 키워드는 원본을 유지한 채 번역본은 **추가**만 됨.
  - 보조 키워드는 엔트리의 Logic 설정에 따라 처리가 갈림. `AND ANY`·`NOT ANY`는 기본 키워드와 같이 병합되지만, `AND ALL`·`NOT ALL`은 조건 자체가 "전부 일치"라서 항목을 추가하면 엔트리가 발동하지 않게 됨. 이 두 경우에는 병합 대신 **번역본으로 교체**함. 따라서 해당 엔트리는 번역 언어에서만 정상 동작함.
- **월드인포 엔트리 정보 표시**: 엔트리를 펼치면 발동 방식(🔵상시 / 🟢키워드 / 🔗벡터), position, depth, order, trigger%가 작은 글씨로 표시됨
- **요청 속도 조절**: 확장 드로어에서 제목 번역 묶음 개수와 요청 간 대기 시간(ms)을 조절할 수 있음. API 분당 요청 한도(예: Vertex AI)에 걸린다면 대기 시간을 늘리세요. (1000ms = 1초)
- 프로바이더별 샘플링 파라미터 개별 설정

### 동봉 정규식·스크립트
프리셋과 캐릭터카드에 정규식이나 JS Runner 스크립트가 들어 있으면, 목록 맨 아래에 접힌 `동봉 정규식 n` · `동봉 스크립트 n` 섹션이 각각 생깁니다.

- **정규식**: 이름만 한 줄로 보임(펼쳐지지 않음). ✦ 번역·↺ 재번역·📛 제목 어느 버튼을 눌러도 📛 제목 번역과 똑같이 이름만 여러 개씩 묶어서 번역하고, 끝나면 번역된 이름이 바로 보임
- **스크립트**: 토글처럼 펼쳐지며 이름과 설명(JS Runner에서 ⓘ를 누르면 나오는 글)이 나옴. ✦ 번역은 이름과 설명을, 📛 제목은 이름만 번역.
- 상단 메뉴 `전체 선택`은 토글에만 적용되며, 각 섹션에 `이 섹션 전체 선택`옵션이 따로 존재함.
- 검색과 👀도 섹션에 적용되며, 검색어에 맞는 항목이 있으면 그 섹션이 펼쳐짐
- 이 번역은 **패널에서 보기 전용**임. 복사·TXT·JSON 내보내기와 JS Runner 제목 번역 스크립트에는 들어가지 않으며, 토큰 수에도 넣지 않습니다.

### 검색
원문과 번역문 양쪽 모두에서 키워드 검색이 가능합니다. 일치하는 부분은 패널에서 하이라이트로 표시됩니다.

### 토큰 수 계산
로드된 항목 전체 토큰 수, **켜진(ON) 토글의 합계**, 선택한 토글의 합계가 표시됩니다. 불러온 직후에는 추정치가 표시되고, 곧 SillyTavern 토크나이저로 계산한 정확한 값으로 바뀝니다.
- 실제 프롬프트에 들어가지 않는 `{{// 주석 }}`은 빼고 셉니다(화면의 원문은 그대로).
- 월드인포는 키워드 줄을 빼고 본문만 계산하며, ON 합계는 켜진 엔트리의 합계.
- `{{setvar}}` 같은 다른 매크로가 실제로 내보내는 양까지는 계산하지 않으므로, SillyTavern이 보내는 실제 토큰과는 차이가 날 수 있습니다.

### 질문하기 (베타)
패널 헤더의 말풍선 버튼을 누르면, 지금 열린 탭에 불러온 프리셋 · 월드인포 · 캐릭터카드를 근거로 AI에게 질문할 수 있습니다. 번역에 쓰는 API 설정을 그대로 사용합니다.

- 예) "답변 분량을 조절하는 토글은 어디에 있나요?", "대사에 색이 입혀지는 이유가 뭔가요?", "이 인물의 가족관계는?"
- 답변 속 **#번호**를 누르면 해당 항목으로 이동해서 토글/엔트리를 펼쳐 보여줍니다. 자료에 없는 번호를 대면 "확인 안 됨"으로 표시됩니다.
- 범위: 불러온 전체 항목, 또는 선택한 항목만.
- 프리셋과 캐릭터카드에 **동봉된 정규식과 JS Runner 스크립트**도 함께 읽습니다. 정규식은 `이름만`(기본) / `내용까지` / `제외`, 스크립트는 포함 여부를 고를 수 있습니다.
- 캐릭터카드는 **임베디드 월드북**도 읽을 수 있습니다(`켜진 엔트리만` 옵션).
- 보내기 전에 예상 토큰과 사용할 모델이 표시됩니다. 분량이 많으면 자동으로 줄여서 보내고 안내됨.
- 마지막 답변 아래의 ↻ 버튼으로 답변을 다시 받을 수 있습니다. 다시 받기가 실패하거나 중단되면 이전 답변이 그대로 남으며 오류로 끝난 질문도 같은 버튼으로 다시 보낼 수 있습니다.
- 기다리는 동안 `보내기`가 `중단`으로 바뀝니다.
- 답변 아래 🔖 버튼으로 답변을 **보관함**에 저장할 수 있습니다. 보관함은 프리셋·월드인포·캐릭터마다 따로 있으며, 질문 창 위쪽의 `보관함` 버튼으로 엽니다. 카드를 누르면 전체 답변이 펼쳐지고, 한 개씩 지우거나 모두 비울 수 있습니다. 브라우저 IndexedDB에 저장되며 SillyTavern을 새로고침해도 남습니다(번역 캐시 삭제와는 무관).
- 대화는 불러온 항목마다 분리되어 있음. 창을 닫거나 다른 항목을 불러왔다가 돌아와도 남아 있지만, 실리태번을 새로고침하면 사라집니다.
- 질문하기의 프리셋 탭에는 **자주 묻는 질문 버튼**이 있습니다: 분량 · 언어 · 시점 · NSFW · 사칭 · 진행 속도 · 상태창/선택지 · 필수 토글. 누르면 바로 질문이 전송됩니다. `이건 뭔가요`는 패널에서 선택한 토글(최대 10개)이 각각 어떤 역할인지 묻습니다.
- 확장 설정의 `질문하기` 구역에서 최대 자료 분량, 최대 답변 길이, 온도를 정할 수 있습니다.

알아둘 점
- **읽기 전용입니다.** "이 토글을 이렇게 고치세요"라고 답해도 확장이 직접 고치지 않습니다.
- **전역 정규식과 캐릭터·채팅 범위 정규식은 읽지 않습니다.**

### 프리셋 비교 (베타)
탭 줄에서 `프리셋` 옆의 작은 ⇄ 탭을 누르면 프리셋 두 개를 토글 단위로 비교합니다.

- **A** = 기준(이전 · 원본), **B** = 비교 대상(새 것 · 수정본). ⇅ 버튼으로 서로 바꿀 수 있습니다.
- 예) A=`원본 프리셋`, B=`내 커스텀` → 내가 원본에서 무엇을 고쳤는지 한눈에 확인
- 위쪽 칩으로 걸러 볼 수 있습니다: `전체` · `변경`(처음 선택) · `추가` · `삭제` · `내용` · `ON/OFF` · `순서` · `이름` · `위치·역할`(실행 조건·덮어쓰기 금지 포함) · `기타`(프리셋 설정값, 동봉 정규식·스크립트) · `동일`
- `전체`는 B의 순서대로 모든 토글을 보여주고, 바뀌지 않은 토글은 흐리게 표시합니다.
- 양쪽에서 이름이 같은 토글을 같은 토글로 봅니다. 이름이 겹치는 토글(구분선 등)이나 이름이 바뀐 토글은 SillyTavern 내부 식별자로 짝을 찾습니다. 이름이 바뀐 토글은 펼친 안쪽에 이전 이름이 표시됩니다.
- 항목을 펼치면 바뀐 부분이 표시됩니다. `−` 취소선(빨강)은 A에만, `+` 초록은 B에만 있는 내용입니다. 바뀌지 않은 줄은 접혀 있고 누르면 펼쳐집니다.
- 번역해 둔 프리셋이면 번역된 제목과 `번역 참고`가 함께 보입니다.
- `A 내용 복사` · `B 내용 복사`로 원문을 클립보드에 받을 수 있습니다.
- **읽기 전용입니다.** 지금 선택된 프리셋은 저장 전 작업 상태의 토글을 읽고, 프리셋 설정값은 저장본 기준으로 비교합니다. API 연결 정보는 읽지도 보여주지도 않습니다.

#### 원본 보존
받은 프리셋을 고쳐 쓰기 전에 원래 상태를 보관해 두고, 나중에 비교 탭에서 "원본 → 내 수정본"을 볼 수 있습니다.
- 프리셋 탭에서 프리셋을 불러온 뒤 둘째 줄 끝의 `📥 원본 보존`을 누릅니다(버튼 줄은 옆으로 밀면 보입니다). SillyTavern에 **저장된 상태 그대로** 보관하며, 저장하지 않은 수정과 프록시 주소·비밀번호 같은 연결 정보는 넣지 않습니다.
- 프리셋 이름마다 하나씩입니다. 이미 보존된 원본이 있으면 덮어쓸지 묻습니다.
- 비교 탭 A 목록 맨 위 `보존본`에서 고를 수 있습니다. A를 비워 두고 B를 고르면, B의 원본을 찾아 A에 자동으로 넣습니다. 같은 이름에 덮어써 쓴 경우는 이름으로, 다른 이름으로 저장해 쓴 경우는 토글이 얼마나 겹치는지로 찾습니다. 후보가 여럿이면 직접 고르도록 알려줍니다.
- 이렇게 **자동으로 들어온 원본은 B를 바꾸면 따라 바뀝니다**(새 B의 원본으로)
- 원본을 보존하지 않았다면 A 목록의 `📁 파일에서 열기`로 프리셋 JSON 파일을 직접 가져와 비교할 수 있습니다. 파일은 이번 접속 동안만 기억하고 어디에도 저장하지 않으며, 원하면 보존본으로 따로 저장할 수 있습니다.
- 보존본은 확장 설정의 `프리셋 원본 보존` 구역에서 목록을 보고 지울 수 있습니다. 
- `실리태번에서 프리셋을 가져올 때 자동으로 보존`을 켜면 SillyTavern의 프리셋 가져오기 때마다 보관합니다(기본 꺼짐, 같은 이름의 원본이 있으면 바꾸지 않음).
- 보존본은 이 브라우저의 IndexedDB에만 있습니다. 기기를 옮길 때는 번역 캐시 백업에서 `보존된 원본도 함께 백업`을 켜세요.

### 복사 및 내보내기
각 탭(프리셋/월드인포/캐릭터) 상단 우측에 3개의 아이콘 버튼이 있습니다.

- **복사**: 클립보드로 복사
- **TXT 내보내기**: 텍스트 파일로 저장
- **JSON 내보내기**: SillyTavern 호환 JSON 파일로 저장

#### 복사 / TXT 내보내기
토글을 일부만 선택해서 그 부분만 복사·내보낼 수 있습니다. 실행 시 **원문만 / 번역문만 / 둘 다** 중 하나를 선택할 수 있고, 번역이 없는 항목은 번역문 모드에서 `(번역없음)`으로 표시됩니다.

#### JSON 내보내기
- **프리셋**은 토글 선택 여부와 관계없이 **항상 전체**를 내보냅니다 (구조가 깨지지 않도록 보장). 프리셋에 동봉된 **정규식과 기타 확장 설정도 함께 내보내집니다**.
- **월드인포**는 토글을 일부만 선택했다면 선택된 엔트리만 내보냅니다.
- **캐릭터카드**는 필드를 일부만 선택했다면 선택된 필드의 번역만 적용해서 내보냅니다. **임베디드 월드북(`character_book`)이 카드 안에 있다면 함께 내보낼지 묻는 창**이 뜨고, 포함을 선택하면 원문 그대로 동봉됩니다.
- 토글 제목도 번역되며, JSON 내보내기 시 번역된 제목은 토글의 이름 필드(프리셋의 `name`, 월드인포의 `comment`)에 들어갑니다.

#### JS Runner 제목 번역 스크립트
프리셋 탭과 월드인포 탭에서 JSON 내보내기를 누르면 형식 선택창이 뜹니다. **JS Runner 제목 번역 스크립트**를 고르면 SillyTavern 본 화면에서 제목이 번역본으로 보이게 해주는 스크립트가 생성됩니다. JS-Slash-Runner 확장(Tavern Helper)에 임포트해서 사용하세요.

- 프리셋: 프롬프트 매니저 항목 이름을 번역본으로 표시합니다.
- 월드인포: 엔트리 제목 위에 번역본을 힌트로 덧붙입니다. 입력창 값은 건드리지 않으므로 월드인포 데이터가 바뀌지 않습니다.
- 화면 표시만 바꿉니다. JS Runner에서 스크립트를 끄면 원래 이름으로 돌아가고 힌트도 사라집니다.
- 다른 확장이 이미 바꿔 놓은 이름은 건드리지 않습니다. 프롬프트 이름을 번역해 보여 주는 기능을 여러 확장에서 함께 켜면 먼저 바꾼 쪽만 보이므로 하나만 켜는 것을 권장합니다.
- 채팅 중 발생하는 화면 변경에는 반응하지 않습니다. 월드인포 스크립트는 엔트리 목록이 바뀔 때만 움직입니다.

#### 파일명
`{소스이름}_{번역언어}.{확장자}` 형식으로 자동 생성되어 브라우저의 기본 다운로드 폴더에 저장됩니다.

### UI
- **플로팅 아이콘**: 옵션으로 활성화 시, 화면에 상시 떠 있는 드래그 가능한 아이콘🐳으로 어디서든 패널을 열 수 있습니다
- 프리셋/월드인포/캐릭터 탭
- 패널 헤더의 새로고침 버튼: ST에 새로 추가/삭제된 항목을 즉시 패널에 반영 (번역 캐시는 보존)
- 원문/번역문 글자 크기 조절
- 테마 6종: Dark, Light, Pink, Mint, Orange, Blue
- 상태 표시줄에 현재 설정된 번역 모델명이 함께 표시됨.

### 지원 언어
한국어, 영어, 일본어, 중국어 간체, 중국어 번체, 폴란드어. 목록에 없는 언어는 직접 입력할 수 있습니다.

2. 본 저장소의 zip 파일을 직접 다운로드하여 SillyTavern의 `data/default-user/extensions/` 폴더 안에 압축 해제

## 참고 사항

- 모든 내보내기는 원본 데이터를 깊은 복제(deep clone)한 뒤 복제본만 수정하므로, **원본 프리셋/월드인포/캐릭터카드는 절대 변경되지 않습니다.**
- 번역이 실패하면(오류·안전 필터 차단·빈 응답) 해당 항목에 이유가 표시되고 기존 번역은 그대로 남습니다. 응답이 출력 길이 한도에 걸려 잘린 경우도 저장하지 않지만, **Claude와 Google(Gemini)은 SillyTavern이 응답이 끝난 이유를 확장에 전달하지 않아** 잘린 번역을 알아채지 못할 수 있습니다.
- 캐릭터카드 JSON 내보내기는 V3 spec에 따라 `data.*` 경로를 정본으로 사용하며, V1 호환용 최상위 중복 필드는 비워서 파일 크기를 최소화합니다. SillyTavern은 import 시 `data.*`를 우선 사용하므로 호환성에 영향이 없습니다.
